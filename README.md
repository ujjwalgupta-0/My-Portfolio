# Ujjwal Gupta — Portfolio

A responsive portfolio built with Next.js App Router and React.

## Run locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

The resume is served at `/Ujjwal-Gupta-Resume.pdf`. Portfolio copy reflects details from the existing site. Update the contact links in `app/page.jsx` if your LinkedIn URL or preferred contact method changes.
